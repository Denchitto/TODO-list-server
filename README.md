# TODO-list


TODO-list позволяет создавать и отслеживать задачи на локальном сервере. Для хранения данных используется встроенная СУБД SQLite.

Доступные возможности:
 
- Добавление задачи
- Удаление задачи
- Поиск задачи в строке поиска по дате/заголовку/комментарию
- Редактирование задачи
- Отметка о выполнении задачи
- Выбор настроек повтора задачи, логика вынесена в пакет service
- Авторизация по паролю и хранение токена в Cookie 


Go: v1.26.1
SQLite: v3.53.3

Выполнены все дополнительные задания. 

Как запустить
---

Для запуска необходимо предварительно скомпилировать код в бинарный файл из директории проекта командой:

```
go build -o [указать путь где будет лежать файл, включая название файла] .
```
Скопировать файлы web, .env в директорию с файлом.

И далее запустить файл из CLI введя имя файла. 

Чтобы не испытывать проблем с совместимостью, альтернативно можно воспользоваться докером, введя команду:

```
docker compose up [-d по желанию, так как в приложении используется логгер]
``` 

Также можно ввести команду из директории проекта:
```
go run main.go
```
В поисковой строке браузера необходимо ввести адрес:

```
http://localhost:7540/login.html
```
Пароль хранится в поле TODO_PASSWORD в файле .env

Дополнительные настройки
---
В файле .env хранятся настройки для запуска. Вы можете изменить:

- Порт (0-65535); по умолчанию 7540
- Путь к базе данных; по умолчанию корень проекта
- Пароль для авторизации
- Секретный ключ для генерации токена

Если не указывать порт и путь, то необходимо изменить файл compose.yaml; см. комментарии в файле
